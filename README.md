# Cinema Admin

This repository is a fork of [hnkarmylla/cinema_admin](https://github.com/hnkarmylla/cinema_admin). 
**Viewable demo (GitHub Pages):** https://lollllz.github.io/cinema_admin/

The Pages site is a static HTML/CSS/JS admin UI served from the `docs/` folder. It includes a movies catalog, an add/edit movie form, a users list, and a mock login. It does not talk to a database.

The PHP files on `main` are the upstream prototype, kept for reference. Real CRUD will be CodeIgniter 4 on PHP later.
